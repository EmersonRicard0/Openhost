Preto piano

OpenHost — guia da marca

Seus hosts, um prompt de distância.

OpenHost é um cliente SSH para Windows feito para quem passa o dia em terminais: NOC, infraestrutura e redes. A marca é preto piano — superfícies escuras e lisas, sem matiz — com um único ponto de cor: o laranja do chevron, que marca onde a ação acontece.

Segoe UI Variable Display · Segoe UI Variable Text · JetBrains Mono

01

Logo

Uma ideia, poucas formas. Use o arquivo certo para o tamanho e o fundo.

Conceito

Um "O" aberto — o host — com o chevron do prompt dentro. A abertura à direita é a porta: o terminal saindo para a rede. O chevron é a única cor da marca.

Regras

  • Uma cor só: o laranja aparece onde o usuário age (foco, seleção, botão primário) e no chevron.
  • Nada de roxo ou azul na interface; a paleta ANSI do terminal é do usuário e fica de fora.
  • Superfícies sem matiz: os neutros são cinzas puros, como laca de piano.
  • No claro use o Laranja profundo; o Laranja OpenHost não passa de 3:1 sobre branco.
  • Estado nunca depende só de cor: conectado, erro e aviso levam também ícone ou texto.

05

Movimento

Movimento com motivo.

Princípios

Rápido

Quem está num incidente não espera animação: 120 a 240 ms.

Com origem

Movimento mostra de onde algo veio: o menu sai do botão, o toast do canto.

Curvas

standardcubic-bezier(0.2, 0, 0, 1)
entercubic-bezier(0.2, 0.8, 0.2, 1)
exitcubic-bezier(0.4, 0, 1, 1)
overshootcubic-bezier(0.34, 1.56, 0.64, 1)
Código
:root{
  --ease-standard: cubic-bezier(0.2, 0, 0, 1);
  --ease-enter: cubic-bezier(0.2, 0.8, 0.2, 1);
  --ease-exit: cubic-bezier(0.4, 0, 1, 1);
  --ease-overshoot: cubic-bezier(0.34, 1.56, 0.64, 1);
  --duration-fast: 120ms;
  --duration-base: 180ms;
  --duration-slow: 240ms;
}

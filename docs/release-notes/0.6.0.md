O OpenHost passa a se atualizar sozinho: esta é a última versão que você precisa baixar e
instalar à mão.

## Novidades

**Atualização pelo próprio app**
- Quando sai uma versão nova, um aviso discreto aparece no canto, sem tirar o foco do terminal,
  com o que mudou. Dá para atualizar, lembrar depois ou pular aquela versão.
- "Atualizar" baixa em segundo plano, com progresso e cancelar. Pronto, escolha entre reiniciar
  agora ou instalar quando fechar o app. Se houver sessões abertas, o app avisa quantas antes.
- Toda atualização é conferida antes de instalar: o arquivo precisa ter a assinatura do projeto e
  bater com o `SHA256SUMS.txt`. Se não bater, nada é instalado.
- No Windows (instalador), no macOS (em Aplicativos) e no AppImage, a atualização é com um clique.
  Nos pacotes `.deb` e `.rpm`, o app baixa o pacote e mostra o comando para instalar.
- Em **Configurações → Sobre**: versão instalada, última verificação, "Procurar atualizações",
  verificação automática (ao abrir e a cada 6 horas) e "Receber versões de teste". "Procurar
  atualizações" também está na paleta de comandos (Ctrl+Shift+P).
- A verificação só consulta a lista de versões publicadas no GitHub. Nada do seu cofre, dos seus
  hosts ou do seu uso é enviado.

## Correções

- Um cofre criado por uma versão mais nova do OpenHost deixava a janela preta. Agora o app avisa
  que é preciso atualizar e não oferece apagar o cofre, que continua inteiro.
- Os atalhos de abrir as configurações e de mover o foco entre painéis podiam ser recusados ao
  salvar as preferências.

## Qual arquivo baixar

| Sistema | Arquivo |
|---|---|
| Windows 10/11 | `OpenHost-0.6.0-windows-amd64-installer.exe` |
| macOS (Intel e Apple Silicon) | `OpenHost-0.6.0-macos-universal.dmg` |
| Ubuntu, Debian e derivados | `openhost_0.6.0_amd64.deb` |
| Fedora, openSUSE e derivados | `openhost-0.6.0-1.x86_64.rpm` |
| Qualquer Linux (sem instalar) | `OpenHost-0.6.0-x86_64.AppImage` |

Quando o build de arm64 do Linux sair, os arquivos `aarch64`/`arm64` também aparecem aqui.
Confira o download com o `SHA256SUMS.txt`; a assinatura dele está em `SHA256SUMS.txt.sig`.

## Requisitos

- **Windows**: 10 ou 11 (64 bits), com o WebView2 (já vem no Windows 11).
- **macOS**: 12 (Monterey) ou mais novo.
- **Linux** (64 bits): WebKitGTK 4.1. Testado no Ubuntu 22.04 e 24.04 e no Fedora 39; Debian 12+ e
  openSUSE Leap 15.5+ têm as mesmas bibliotecas.

## Primeira abertura no macOS

O app ainda não tem assinatura da Apple, então o macOS avisa na primeira vez:

1. Arraste o OpenHost para Aplicativos.
2. Clique com o botão direito no OpenHost → **Abrir** → **Abrir** de novo no aviso.
3. Se não aparecer o botão (macOS 15+): **Ajustes do Sistema → Privacidade e Segurança** →
   **Abrir Mesmo Assim**.

Pelo Terminal: `xattr -dr com.apple.quarantine /Applications/OpenHost.app`

## Instalar no Linux

```sh
# Ubuntu e Debian
sudo apt install ./openhost_0.6.0_amd64.deb

# Fedora
sudo dnf install ./openhost-0.6.0-1.x86_64.rpm

# AppImage
chmod +x OpenHost-0.6.0-x86_64.AppImage
./OpenHost-0.6.0-x86_64.AppImage
```

Desinstalar o pacote não apaga o cofre.

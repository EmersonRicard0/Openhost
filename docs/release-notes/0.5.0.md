Terminais lado a lado na mesma aba e o OpenHost reconhecendo equipamentos de rede.

## Novidades

**Vários terminais na mesma aba**
- Arraste uma aba sobre o terminal de outra e solte no lado em que ela deve ficar (esquerda,
  direita, em cima ou embaixo). Até 4 sessões por aba.
- Divisórias ajustáveis: arraste, dê dois cliques para igualar ou use as setas do teclado.
- Troque de painel com o clique ou com Ctrl+Alt+Setas (⌥⌘+Setas no macOS); o painel ativo fica
  destacado e é ele que recebe a digitação, a busca e o colar.
- Cada painel tem "Separar em nova aba" e "Fechar painel"; arrastar o cabeçalho reorganiza o grupo
  ou, solto na barra de abas, separa o painel. Nenhuma sessão reconecta.

**Equipamentos de rede**
- Ícone do fabricante detectado sozinho ao conectar: Huawei, ZTE, Datacom, Cisco, Juniper,
  Hillstone, Fortinet e MikroTik, além dos sistemas que já eram reconhecidos.
- A detecção roda depois que o terminal abre, sem atrasar a conexão e sem enviar comandos a
  equipamentos de rede. Nada do que o servidor mostra é gravado em disco ou em log.

**Interface**
- Barra de abas rola com a roda do mouse ou arrastando o fundo, com setas e lista de todas as abas.
- Recolher a barra lateral por uma alça na borda.
- Quadrados dos hosts numa cor só, com o logo do sistema ou do fabricante na cor da marca.
- Barra de status mais enxuta: latência, encaminhamentos e cofre.

## Correções

- Teclas digitadas muito rápido podiam chegar fora de ordem ao shell.

## Qual arquivo baixar

| Sistema | Arquivo |
|---|---|
| Windows 10/11 | `OpenHost-0.5.0-windows-amd64-installer.exe` |
| macOS (Intel e Apple Silicon) | `OpenHost-0.5.0-macos-universal.dmg` |
| Ubuntu, Debian e derivados | `openhost_0.5.0_amd64.deb` |
| Fedora, openSUSE e derivados | `openhost-0.5.0-1.x86_64.rpm` |
| Qualquer Linux (sem instalar) | `OpenHost-0.5.0-x86_64.AppImage` |

Quando o build de arm64 do Linux sair, os arquivos `aarch64`/`arm64` também aparecem aqui.
Confira o download com o `SHA256SUMS.txt`.

## Requisitos

- **Windows**: 10 ou 11 (64 bits), com o WebView2 (já vem no Windows 11).
- **macOS**: 12 (Monterey) ou mais novo.
- **Linux** (64 bits): WebKitGTK 4.1. Testado no Ubuntu 22.04 e 24.04 e no Fedora 39; Debian 12+ e
  openSUSE Leap 15.5+ têm as mesmas bibliotecas.

## Primeira abertura no macOS

O app ainda não tem assinatura da Apple, então o macOS avisa na primeira vez:

1. Arraste o OpenHost para Aplicativos.
2. Clique com o botão direito no OpenHost → **Abrir** → **Abrir** de novo no aviso.
3. Se não aparecer o botão (macOS 15+): **Ajustes do Sistema → Privacidade e Segurança** →
   **Abrir Mesmo Assim**.

Pelo Terminal: `xattr -dr com.apple.quarantine /Applications/OpenHost.app`

## Instalar no Linux

```sh
# Ubuntu e Debian
sudo apt install ./openhost_0.5.0_amd64.deb

# Fedora
sudo dnf install ./openhost-0.5.0-1.x86_64.rpm

# AppImage
chmod +x OpenHost-0.5.0-x86_64.AppImage
./OpenHost-0.5.0-x86_64.AppImage
```

Desinstalar o pacote não apaga o cofre.

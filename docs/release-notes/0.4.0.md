O OpenHost agora roda no **Windows, Linux e macOS**, e traz hosts de outros programas.

## Novidades

**Linux e macOS**
- O mesmo app nos três sistemas: cofre criptografado, SSH, SFTP, encaminhamento de portas,
  terminal local, perfis e importar/exportar.
- Terminal local com os shells do sistema (bash, zsh, fish e o que estiver em `/etc/shells`).
- Agente SSH pelo `SSH_AUTH_SOCK`.
- No macOS: botões nativos da janela, atalhos com ⌘ (⌘T, ⌘W, ⌘, …) e copiar/colar com ⌘C/⌘V.
- O cofre fica em `~/.config/ShellVault` no Linux e em `~/Library/Application Support/ShellVault`
  no macOS, acessível só pelo seu usuário.

**Importar e exportar hosts**
- Importa de OpenSSH (`~/.ssh/config`), PuTTY, KiTTY, MobaXterm, SecureCRT, planilhas CSV e
  arquivos `.openhost`, sempre com prévia antes de gravar. A última importação pode ser desfeita.
- Exporta para `.openhost` (com chaves, criptografado com uma senha sua), OpenSSH ou CSV.
- Senhas salvas em outros programas nunca são lidas.

## Qual arquivo baixar

| Sistema | Arquivo |
|---|---|
| Windows 10/11 | `OpenHost-0.4.0-windows-amd64-installer.exe` |
| macOS (Intel e Apple Silicon) | `OpenHost-0.4.0-macos-universal.dmg` |
| Ubuntu, Debian e derivados | `openhost_0.4.0_amd64.deb` |
| Fedora, openSUSE e derivados | `openhost-0.4.0-1.x86_64.rpm` |
| Qualquer Linux (sem instalar) | `OpenHost-0.4.0-x86_64.AppImage` |

Quando o build de arm64 do Linux sair, os arquivos `aarch64`/`arm64` também aparecem aqui.
Confira o download com o `SHA256SUMS.txt`.

## Requisitos

- **Windows**: 10 ou 11 (64 bits), com o WebView2 (já vem no Windows 11).
- **macOS**: 12 (Monterey) ou mais novo.
- **Linux** (64 bits): WebKitGTK 4.1. Testado no Ubuntu 22.04 e 24.04 e no Fedora 39; Debian 12+ e
  openSUSE Leap 15.5+ têm as mesmas bibliotecas.

## Primeira abertura no macOS

O app ainda não tem assinatura da Apple, então o macOS avisa na primeira vez:

1. Arraste o OpenHost para Aplicativos.
2. Clique com o botão direito no OpenHost → **Abrir** → **Abrir** de novo no aviso.
3. Se não aparecer o botão (macOS 15+): **Ajustes do Sistema → Privacidade e Segurança** →
   **Abrir Mesmo Assim**.

Pelo Terminal: `xattr -dr com.apple.quarantine /Applications/OpenHost.app`

## Instalar no Linux

```sh
# Ubuntu e Debian
sudo apt install ./openhost_0.4.0_amd64.deb

# Fedora
sudo dnf install ./openhost-0.4.0-1.x86_64.rpm

# AppImage
chmod +x OpenHost-0.4.0-x86_64.AppImage
./OpenHost-0.4.0-x86_64.AppImage
```

Desinstalar o pacote não apaga o cofre.
